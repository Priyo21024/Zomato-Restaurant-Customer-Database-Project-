**Zomato — Restaurant & Customer Database (DBMS Project)**

This repository contains the **DBMS Course Project** implemented using **MySQL**.  

The project models  **Zomato**, and focuses on restaurants, customers, orders, menu items, delivery partners, and reviews.

This project includes:
- Complete **EER Diagram**
- **SQL Schema** (table creation scripts)
- **Sample Data Insertion**

The goal was to design and implement a relational database for Zomato: Food Delivery Platform and keeping this in mind the database focuses on:

- Managing restaurants and their menus  
- Capturing customer information  
- Handling orders and payments  
- Tracking delivery partners  
- Storing customer reviews and ratings  
- Representing real-world relational dependencies
